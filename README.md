## SOS Santa Rita

- O SOS Santa Rita foi criado como atividade em grupo com o objetivo de auxiliar a população e a defesa civil em situações de chuvas fortes e enchentes

## Problema

- O SOS Santa Rita busca facilitar o primeiro contato de ajuda em uma situação de risco

## Tecnologias Utilizadas

- Java
- Programação Orientada à Objetos (POO)
- Java swing (interface)
- MYSQL (BD)

## Funcionalidades

- O usuário pode registrar uma ocorrência, pedir auxílio da defesa civil, se cadastrar em abrigo e visualizar alertas postados

## Organização

- O projeto está organizado em subpastas. Uma é utilizando poo em java para criar as classes cumprindo as regras de negócios propostas na idealização do projeto (model), outra pasta é responsável pela conexão ao banco de dados (dao) e outra é referente à interface (view).
